الإعدادات

الربط مع n8n:
• استقبال الحجوزات: الفورم بتاعك في n8n بيسجل الحجز، والموقع بيسحبه كل 30 ثانية. لو كتبت رابط n8n (Webhook من نوع GET بيرجّع JSON فيه الحجوزات) فوق، الموقع هيسحب منه مباشرة. لو سبته فاضي، هيقرا من ملف bookings.json اللي n8n بيحدّثه على GitHub.
• الأعمدة المقبولة: الاسم، الهاتف، الخدمة، التاريخ، الوقت، الحالة، ملاحظات (patientName / phone / serviceName / date / time / status / notes بالإنجليزي كمان).
• إرسال التحديثات: لما تغيّر حالة حجز (تم / إلغاء) بيتبعت لرابط الـ POST. ملاحظات الدكتور والبيانات الطبية مش بتتبعت.
• لو سحبت من رابط n8n مباشرة لازم تفعّل CORS في الـ Webhook node (Allowed Origins).
